# Taste of Africa Platform 🍲🌍

A responsive, frontend-driven e-learning web application that allows premium subscribers to master authentic African cuisines through interactive text recipes and streaming video tutorials.

## 🚀 Features

- **Premium Subscriber Gate:** Restricts access to exclusive culinary video courses and high-end recipes.
- **Interactive Recipe Guide:** Dynamic step-by-step cooking instructions with integrated ingredient checklists.
- **Dual-Media Learning:** Seamlessly switch between detailed text documentation and high-definition video player tutorials.
- **Fully Responsive Layout:** Optimized for mobile phones, tablets, and desktop displays so users can cook easily in the kitchen.

## 🛠️ Tech Stack

- **HTML5:** Semantic structure for accessible and SEO-friendly recipe articles.
- **CSS3:** Custom layouts utilizing Flexbox, Grid, and smooth transitions for a premium UI feel.
- **Vanilla JavaScript (ES6+):** Dynamic DOM manipulation, state management for user subscription access, and custom video controls.

## 💻 Getting Started

To view and run this project locally, follow these simple steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   ```

2. **Navigate into the directory:**
   ```bash
   cd taste-of-africa-platform
   ```

3. **Open the project:**
   Open `index.html` directly in your browser, or run it using a local development server like VS Code's **Live Server** extension.
